# Phoneme Activity Builder - Assessment 1

This is my Assessment 1 frontend project. It is a small Next.js app for making phoneme based Wordle and Word Search activities.

## Pages

- Home
- About
- Wordle
- Word Search
- Settings

## Main features

- phoneme based Wordle game
- phoneme Word Search game
- phoneme hover hints
- light and dark themes saved with cookies
- compact layout option saved with cookies
- responsive layout for smaller screens
- download a standalone HTML file for each activity

For Assessment 1 the Wordle has one fixed target word and the Word Search has five fixed words. A database and larger word list can be added in later assessments.

## Run the project

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
